# 🔐🧠 Secure AI-Based Medical Image Diagnosis System

A hybrid **Cybersecurity + Artificial Intelligence** project that combines deep learning with encryption techniques to ensure **secure medical image diagnosis**. The system not only predicts diseases from medical images but also protects sensitive data using cryptographic methods.

---

## 🚀 Key Highlights

* 🧠 AI-powered disease detection using deep learning
* 🔐 Secure image storage & transmission using AES encryption
* 🔓 Decryption pipeline for authorized access
* 🌐 Web-based interface using Flask
* 👤 User authentication system
* ⚡ Real-time prediction with secure processing

---

## 🧩 Project Type

* 🔐 **Cybersecurity Project** (Data Encryption & Protection)
* 🧠 **Artificial Intelligence / Deep Learning Project**
* 🌐 **Full Stack Web Application**

---

## 🛠️ Tech Stack

* **Backend:** Flask
* **AI Model:** TensorFlow / Keras
* **Libraries:** NumPy, OpenCV, Matplotlib, Scikit-learn, Pillow
* **Security:** PyCryptodome (AES Encryption), Flask-Login
* **Other Tools:** Werkzeug

---

## 🔐 Security Architecture

* AES-based encryption applied to sensitive medical images
* Secure key handling for encryption/decryption
* Protection against unauthorized access
* User authentication with session management

## 🧪 AI Model Details

* CNN-based architecture for medical image classification
* Trained on MRI brain tumor dataset
* Image preprocessing: resizing, normalization, augmentation
* Multi-class classification support

---

## 🔄 Workflow

1. User uploads medical image
2. Image is **encrypted using AES**
3. Secure storage / transmission
4. Image is **decrypted for processing**
5. AI model performs prediction
6. Results displayed securely to user
